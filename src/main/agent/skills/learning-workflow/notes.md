# 创建与增量更新笔记

先查询已登记的 notes，沿用当前入口和章节范围。若已有多份旧笔记，核对覆盖范围与用户选择后登记当前入口，保留旧文件；不凭最新修改时间认定正确版本，也不批量改写用户原有笔记。

需要详细笔记时使用可用的 study-notes 技能。沿课件章节顺序合并连续主题，讲清概念、直觉、公式假设、符号、单位、关键推导、例题和反例；关键结论保留真实文件页码。新增解释/自拟例子与原课件内容分明，不能用更多字数代替讲清难点。

## 安全地修改当前笔记

1. 读取当前笔记与用户批注，核对新资料版本及受影响的主题。
2. `inspect_learning_note` 取得当前 revision；再次读取原文后，使用 `update_learning_note` 的 expectedRevision 和 edits 精确替换唯一段落。新笔记使用 expectedRevision=null 与 createText。
3. 不覆盖用户批注、个人观点或未解决问题。无法区分作者时，将更正放入明确的补充区，或保存修订副本供比较。已有文件不使用 write/bash 整篇覆盖来绕过版本校验。
4. 冲突时重新读当前版本，只合并必要变化。命令自动保存修改前快照；需要撤回时先核对当前版本，再用 `restore_learning_note`。快照保存在本机内部目录，不另交付备份文件。
5. 核对来源→知识主题→解释/推导→代表性应用的覆盖。关键数值实际复算；用一项解释、一项应用或条件变化检查仅凭笔记能否走通，发现缺失就补入正文。只核对声明覆盖的范围，未读内容不填已完成。
6. `save_learning_note` 登记当前文件及真实 coveredSources/sourceId/version。先确认引用的资料确已读取；登记不等于整门课程全部完成。课件新增而尚未纳入时留待后续整理，原版本变化后重新核对受影响段落。

默认交付课程学习笔记中的一个 Markdown 当前入口，不自动复制 HTML、PDF、总集和检查报告。用户要求分章时保持各章清晰入口与短索引。学习检查的内部结果不作为用户已掌握的证据。
